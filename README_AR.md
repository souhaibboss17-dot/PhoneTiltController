# Phone Tilt Controller — نسخة تجريبية

هذا مشروع Android أولي لقراءة ميل الهاتف وإرسال زاوية الميل عبر Bluetooth إلى هاتف آخر.

## الحالة والقيود
- هذا **ليس APK جاهزًا**؛ يجب بناء المشروع أولًا.
- لا يحقن بيانات مستشعر وهمية داخل Rally Fury، ولا يتحكم باللعبة مباشرةً. حاليًا الهدف اختبار نقل زاوية الميل فقط.
- قد تحتاج إلى اختيار/تحديد الجهاز المقترن الصحيح؛ النسخة الحالية أولية وغير مختبرة على جهازين فعليين.

## بناء APK عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. افتح تبويب **Actions**.
3. اختر **Build Android APK** ثم **Run workflow**.
4. بعد انتهاء البناء، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
5. نزّل `PhoneTiltController-debug-apk`؛ داخله `app-debug.apk`.

## تجربة أولية
1. ثبّت APK على الهاتفين.
2. اقترن الهاتفان من إعدادات Bluetooth.
3. على Galaxy A07 اختر `Receiver (Galaxy A07)` واضغط Start.
4. على Redmi A1+ اختر `Controller (Redmi)` واضغط Start.
5. وافق على صلاحيات Bluetooth إذا طُلبت.

قد لا يعمل الاتصال حتى على كل الأجهزة في هذه النسخة الأولية، ولا يُضمن توافقها مع Rally Fury.
